Help Desk Management System

Project Overview

The Help Desk Management System is a Java-based desktop application developed using Java Swing. It helps users create support tickets, view ticket details, and track the status of issues in an organized manner.

The application provides a simple graphical interface for managing support requests efficiently.

Objectives

- Create support tickets with user names and problem descriptions.
- Display ticket details in an organized table.
- Track ticket status as Open or Resolved.
- Provide a simple and user-friendly graphical interface.
- Demonstrate basic ticket management using Java Swing.

Technologies Used

- Java: Core programming language.
- Java Swing: Graphical User Interface (GUI).
- ArrayList: Temporary storage of ticket objects.
- JTable: Displays ticket information in rows and columns.
- VS Code: Code editing and development.
- JDK: Java compilation and execution.

 Key Features

1. Ticket Creation: Create new support tickets with user details and problem descriptions.
2. Ticket Viewing: View all created tickets in a structured table.
3. Status Update: Change the selected ticket status from Open to Resolved.
4. Live Dashboard Counts: Display total, open, and resolved ticket counts.
5. Clear Fields: Clear input fields without deleting existing tickets.

Project Modules

- Ticket Creation
- Ticket Viewing
- Status Update
- Ticket Storage
- Dashboard and User Interface


🎓 Conclusion

The Help Desk Management System demonstrates how Java Swing can be used to develop a simple desktop application for organized support ticket management. It provides basic ticket creation, viewing, and status tracking features.
